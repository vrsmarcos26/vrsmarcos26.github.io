# Portfólio Pessoal - Marcos Vinícius (vrsmarcos26)

## 🚀 Sobre o Projeto

Este é o meu portfólio pessoal, desenvolvido do zero com o objetivo de ser uma vitrine moderna, dinâmica e profissional para meus projetos, habilidades e experiências. O site foi construído utilizando apenas **HTML, CSS e JavaScript puros (Vanilla JS)**, sem o uso de frameworks, para demonstrar um conhecimento sólido das tecnologias fundamentais da web.

O projeto é totalmente gerenciado por um arquivo de configuração central e integrado com a API do GitHub para exibir meus projetos em tempo real.

### ✨ [Acesse a Versão Online](https://vrsmarcos26.github.io/)

---

## 🛠️ Funcionalidades Principais

Este portfólio não é apenas uma página estática. Ele foi construído com diversas funcionalidades para ser de fácil manutenção e oferecer uma ótima experiência ao usuário:

* **Conteúdo 100% Dinâmico:** Todas as informações de texto (biografia, experiências, habilidades, etc.) são gerenciadas por um único arquivo `config.js`, permitindo atualizações fáceis sem tocar no HTML.
* **Projetos em Tempo Real:** Integração total com a **API do GitHub**. Meus projetos são buscados e exibidos automaticamente com base nos tópicos (`tags`) dos meus repositórios. Basta taguear um novo projeto com `portfolio` e ele aparece no site.
* **Suporte a Múltiplos Idiomas (PT/EN):** O site oferece tradução completa para Português e Inglês. A escolha do usuário é salva localmente, e o idioma do navegador é detectado na primeira visita.
* **Tema Claro (Light) e Escuro (Dark):** Inclui um seletor de tema que também salva a preferência do usuário no navegador.
* **Design Responsivo:** Layout adaptável para uma visualização perfeita em qualquer dispositivo, de desktops a celulares.
* **Carrossel de Certificações:** Seção interativa e rotativa para exibir cursos e certificações, construída com a biblioteca leve Glider.js.
* **Foco em Acessibilidade:** Implementação de navegação via teclado (`:focus-visible`), HTML semântico e atributos ARIA para garantir uma experiência acessível para todos.

## ⚙️ Instalação e Configuração

Como este é um projeto de front-end puro, não há dependências complexas. Para rodar localmente, siga os passos:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/vrsmarcos26/vrsmarcos26.github.io.git](https://github.com/vrsmarcos26/vrsmarcos26.github.io.git)
    ```

2.  **Navegue até a pasta do projeto:**
    ```bash
    cd vrsmarcos26.github.io
    ```

3.  **Abra o arquivo `index.html` no seu navegador.**
    * *Dica: Para uma melhor experiência de desenvolvimento, utilize uma extensão como o "Live Server" no VS Code.*

### ✏️ Como Personalizar para Seu Uso

Este portfólio foi projetado para ser facilmente adaptável. Para usá-lo com suas informações:

1.  **Abra o arquivo `config.js`:** Este é o "painel de controle" do site.
2.  **Altere as informações:** Modifique seu nome, username do GitHub, links de redes sociais, textos da biografia, experiências, habilidades e certificações.
3.  **Adicione seus projetos no GitHub:** Crie seus repositórios e adicione o tópico `portfolio` para que eles apareçam automaticamente. Adicione outros tópicos para a filtragem (ex: `full-stack`, `cibersecurity`).
4.  **Troque a foto de perfil:** Substitua a imagem em `/assets/img/` pela sua foto e atualize o caminho no `index.html`.

# Portfólio Pessoal & Showcase Técnico - Marcos Vinícius (vrsmarcos26)

## 🚀 Sobre o Projeto

Este é o meu portfólio pessoal e vitrine técnica, desenvolvido para refletir minha atuação profissional como **Purple Teamer (Cibersegurança Ofensiva e Defensiva)** e **Desenvolvedor Full-Stack / DevSecOps**. 

O projeto foi construído utilizando tecnologias modernas de mercado, unindo performance, design imersivo em **Glassmorphism**, elementos **3D interativos** e suporte completo a múltiplos idiomas (PT/EN).

### ✨ [Acesse a Versão Online](https://vrsmarcos26.github.io/)

---

## 🛠️ Funcionalidades e Diferenciais

* **Arquitetura Orientada a Dados (Data-Driven):** Todo o conteúdo do site (experiências, habilidades, certificações) é gerenciado de forma centralizada em um arquivo de configuração (`config.ts`), facilitando a manutenção e futuras atualizações.
* **Projetos Dinâmicos via API do GitHub:** Integração nativa com o GitHub para buscar e exibir repositórios em tempo real com base em tags e tópicos específicos (`portfolio`).
* **Suporte Bilíngue (PT / EN):** Sistema de tradução instantânea em tempo real cobrindo toda a interface, descrições e histórico profissional.
* **Modo Claro & Escuro (Dark/Light Theme):** Alternância fluida de temas adaptada para garantir o contraste perfeito em ambientes operacionais.
* **Fator Visual 3D (Three.js / React Three Fiber):** Elementos geométricos interativos em wireframe na página inicial que respondem dinamicamente ao movimento do cursor.
* **Terminal CLI Interativo:** Um mini-terminal embutido no site (`PurpleTeam-CLI`) onde recrutadores e entusiastas podem executar comandos reais (`whoami`, `skills`, `contact`, `sudo su`) para interagir com o portfólio.
* **Download Direto de Currículos:** Acesso rápido a versões segmentadas do CV (Cibersegurança e Desenvolvimento).
